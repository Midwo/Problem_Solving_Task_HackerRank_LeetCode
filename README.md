# 1. Problem Solving — HackerRank & LeetCode (Task with C# and MS SQL)

This repository contains my solutions to algorithmic challenges from HackerRank and LeetCode, implemented primarily in C# (.NET).

Some tasks also include **MS SQL** solutions, stored alongside the corresponding **C#** tasks within the same platform folders.

All included methods represent fully working solutions that successfully pass the official test cases on their respective platforms.

The project is organized as a **.NET console application** with a clear folder structure and optional aggregated classes for easier execution.

# 3. Running Tasks

> [!IMPORTANT]
> In Program.cs you will find commented code blocks that allow you to run a method/task.

To execute a task:

1. Uncomment the desired code block.

2. Choose whether to use:

   * the individual class (e.g., LeetCode_TaskNumber, HackerRank_TaskNumber),

   * or the combined class (LeetCodeALL, HackerRankALL).

3. Run the project.

# 4. Project Principles

1. Every task is implemented as a standalone method.

2. All methods are verified and pass the official HackerRank or LeetCode test cases.

3. Tasks are ordered ascending by a problem number.

 # 5. Technologies

This repository includes tasks implemented in:

C# (.NET):

 * algorithms
 * data structures
 * arrays, strings, hashing
 * dynamic programming
 * math & logic problems

MS SQL:

* SQL challenges included within HackerRank/LeetCode folders
* joins, aggregations

SQL tasks are stored next to their C# counterparts for consistency and easier navigation.
